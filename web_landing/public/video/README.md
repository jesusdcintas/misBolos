# Vídeo Promocional de MisBolos

Este directorio está reservado para el vídeo de presentación de la aplicación MisBolos.

## Archivo esperado:
- **Nombre:** `promo.mp4`
- **Ubicación:** `public/video/promo.mp4`

## Detalles del reproductor en la web:
El reproductor de vídeo del Hero está configurado para:
- Reproducirse en bucle (`loop`).
- Estar silenciado por defecto (`muted`).
- Reproducirse automáticamente en dispositivos móviles (`playsinline` y `autoplay`).
- Omitir los controles estándar para mantener una estética limpia y premium, o bien ofrecer controles discretos.

Si este archivo no existe, la landing page mostrará un elegante reproductor de vídeo simulado con CSS que describe el contenido del vídeo promo.
