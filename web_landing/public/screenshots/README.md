# Capturas de Pantalla / Capturas de Producto de MisBolos

Este directorio está reservado para almacenar las imágenes de capturas reales de la aplicación MisBolos.
El diseño de la landing page cargará estas imágenes por defecto. Si se añaden aquí, reemplazarán automáticamente a los elegantes mockups vectoriales/CSS por defecto sin romper el layout.

## Nombres de archivos esperados:

1. `dashboard.png` - Vista principal del panel de control (resumen de ingresos, oficiales/privados y alertas).
2. `calendario.png` - Calendario mensual de bolos y sus diferentes estados (confirmado, cobrado, etc.).
3. `facturas.png` - Vista de creación/detalle de factura con el modo fiscal avanzado.
4. `gastos.png` - Interfaz de registro de gastos y tickets con la lectura inteligente.
5. `finanzas.png` - Resumen financiero, balance de IVA e IRPF y cierre del trimestre.
6. `asistente.png` - Chat interactivo del asistente de negocio inteligente.
7. `ajustes.png` - Perfil de configuración de datos fiscales, seguridad (PIN/biometría) y apariencia.

## Formato recomendado:
Se recomienda que las imágenes tengan fondo transparente o estén recortadas adecuadamente para encajar en los marcos de los dispositivos simulados por la web (mockups).
